# React Counter App

A simple Counter application created using React.js for practice.

## Features

- Increase the counter
- Reset the counter
- Simple and clean interface
- Interactive buttons with hover effects

## Technologies Used

- React.js
- JavaScript
- JSX
- CSS
- Vite

## React Concepts Practiced

- React Components
- useState Hook
- Event Handling
- JSX
- Props
- CSS Styling
